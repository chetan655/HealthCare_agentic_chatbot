# ACHARYA: agentic_chatbot_for_healthcare_assistance

Access to healthcare assistance can be challenging due to long waiting lines, difficulty finding doctors, and confusion around medicine or symptoms. Our solution, **ACHARYA**, tries to address these issues by helping in finding relevant **nearby hospitals, medicine label OCR, personalized health related sugestions, symptom diagnosis**, 
In short, making healthcare more accessible and user friendly using power of AI.
